JWTGuard — JWT Security Analysis Chrome Extension Featured

A Chrome extension for defensive JWT security testing, built in a team of five. The extension passively intercepts live outbound HTTP requests, extracts JWTs from Authorization headers, cookies, and URL parameters, and binds each token to its original request context at capture. A deterministic variant engine classifies the algorithm family (HMAC, RSA/ECDSA, none) and generates up to 29 targeted test tokens — alg=none bypass, algorithm confusion (RS256→HS256), weak HMAC brute-forcing, claim tampering for privilege escalation, and header-parameter injection including kid path traversal. Every mutated token stays RFC-compliant via a centralised Base64URL encoding pipeline. A controlled replay layer reinserts each variant into the original request with full context preserved, then compares responses across status code, body length, and content hash. A live header indicator surfaces JWT detection state in real time.

Motivation Built in response to the rise in JWT-related CVEs through 2025 and the gap left by tools like Burp's JWT Editor and jwt_tool, which focus on mutation but require manual replay and manual response interpretation.

Wi-Fi Security Audit Suite

A self-contained, handheld wireless security auditing device built from the ground up on an ESP32-S3 with an integrated LCD. Runs fully offline — no laptop, no external software — navigable with two physical buttons. Core features: passive real-time scanning and threat detection; compliance-audit mode producing timestamped JSON reports saved to SD card; an autonomous monitoring mode that continuously classifies threats across rotating sessions; a web dashboard served from the device's own access point for log browsing and filtering; PCAP capture of raw wireless frames compatible with Wireshark; and USB-based data collection for physical assessments. Firmware written entirely in C on FreeRTOS with a modular 12-component architecture, custom 802.11 frame parsing, and a structured CSV/JSON logging pipeline.

05

Randomised Dynamic Quantum (RDQ) CPU Scheduler

A C implementation of the Randomised Dynamic Quantum scheduling algorithm, derived from a real academic paper, for an Operating Systems module. Eliminates the fixed-quantum problem by generating a random quantum per round, bounded by a computed min (median burst time) and max (largest burst). Processes are sorted by burst time to minimise the convoy effect. Three modes: user-defined fixed-quantum sequence, single dynamic run, and a multi-run mode that repeats the algorithm N times and averages statistics for fairness. Each run outputs a full Gantt chart and metrics table.

Team-level work Benchmarked against four other scheduling algorithms across seven standardised test cases (uniform, increasing, decreasing, and high-variance workloads). RDQ was run ten times per case with averaged results, followed by composite scoring across all metrics and scenarios.
